# Проверка «Мои задачи» V2

Проверено 10 ноября 2026 года, Windows. Браузерные сценарии запускались на production-сборке через `vite preview`.

## Итог

- `npm install` для новых зависимостей и обновление lockfile выполнены. Версия проекта и lockfile — 2.0.0.
- `npm run lint` — успешно, без ошибок и предупреждений ESLint.
- `npm run build` — успешно.
- `npm audit` — 0 известных уязвимостей на момент проверки.
- Финальный `npm test`: **264 passed, 46 skipped, 0 failed**, без повторных попыток и flaky-тестов. Длительность — около 159 секунд.
- Ошибок JavaScript, console.error и загрузки ресурсов в итоговых проверяемых сценариях не обнаружено.
- axe не обнаружил нарушений проверяемых правил WCAG 2 A/AA и 2.1 AA в пустом и заполненном списке, обеих темах и открытом редакторе. Проверки цветов выполняются после завершения переходов. Это автоматическая проверка, а не сертификат доступности.

Пропуски распределяют сценарии по подходящим профилям: мышь и физическая клавиатура проверяются в desktop, касания — в mobile. Матрица размеров не дублируется в мобильных профилях. Полноценные touch drag и scroll через CDP проверяются только в мобильном Chromium; у WebKit этого интерфейса нет. Все четыре обязательные функции проверяются во всех пяти профилях.

## Разрешения

Проверены 1920×1080, 1440×900, 1366×768, 1024×768, 820×1180, 768×1024, 430×932, 390×844, 375×812, 360×800, **320×568**, а также горизонтальное окно **844×390**.

Матрица выполнена в Chromium, Firefox и WebKit с десятью задачами и словом из 200 символов. Проверялись отсутствие горизонтальной прокрутки, положение удаления, размеры кнопок и шрифт поля. Отдельно проверено мобильное окно 320×340 при вводе, редактировании и сохранении.

## Основные функции и совместимость

- Добавление кнопкой и Enter, очистка и фокус поля, пробелы по краям, пустой ввод, максимум 200 символов.
- Выполнение и возврат в активные, зачёркивание и правильный счётчик.
- Удаление выбранной активной, выполненной и единственной задачи; сохранение остальных.
- Сохранение идентификаторов, названий, статусов, приоритетов, дат и порядка после reload и повторного открытия вкладки.
- Перенос массива V1 с прежними id, статусами и порядком; medium/null по умолчанию и резервная копия исходного JSON.
- Пустое хранилище, повреждённый JSON, null, объект вместо массива, неверные типы, пустые и слишком длинные названия, повторяющиеся id.
- Неверные дополнительные свойства заменяются безопасными значениями без потери основных свойств задачи.
- Запрет localStorage и переполнение квоты: интерфейс остаётся работоспособным и показывает предупреждение.
- HTML-подобные названия выводятся текстом, без создания тегов и выполнения кода.
- Быстрое добавление десяти задач, последовательное удаление, список из ста задач и прокрутка до последней строки.
- Быстрый reload сразу после удаления не возвращает задачу, даже если визуальная анимация ещё не завершена.

## Новые функции

- Системная тема при первом открытии; сохранённая тема имеет приоритет. Атрибут темы проверен уже при DOMContentLoaded.
- Переключение без reload и потери черновика, восстановление после reload, неверная настройка и запрет её записи.
- Редактирование: Enter, Escape, отмена кнопкой, пустые строки, trim, предел 200 символов, восстановление фокуса.
- Изменение названия, приоритета и даты выполненной задачи с сохранением её id, статуса и положения.
- Три приоритета при создании, средний по умолчанию и сброс параметров формы после добавления.
- Назначение, изменение и удаление дедлайна.
- Вчера / сегодня / завтра, выполненная задача и переход через полночь.
- Одна календарная дата при одинаковом моменте времени в Europe/Moscow и America/Los_Angeles: просрочка зависит от местного дня, сдвига даты нет.
- Общий прогресс при поиске и фильтрах, 0% у пустого списка и 100% у завершённого.
- Поиск без учёта регистра по русским и английским названиям, пустой результат, очистка, сочетание с фильтром и удаление найденного.
- `/` вне полей; обычный ввод `/` внутри полей; первое и повторное Escape в поиске.
- Порядок через Alt + стрелки и через захват пробелом со стрелками; сохранение порядка и свойств.
- Перетаскивание мышью, отмена Escape; невозможность сортировки с поиском и фильтром.
- Touch drag за ручку и обычная сенсорная прокрутка текста: порядок и статусы не меняются случайно.
- Tab, Enter и Space, видимый фокус, доступные имена кнопок и полей.
- Reduced motion отключает CSS-анимации и переходы; настройки dnd-kit также учитывают это предпочтение.

## Найденное и исправленное

1. Ожидание удаления до конца анимации могло возвращать задачу при мгновенном reload. Запись теперь сразу исключает удаляемые id; визуальная строка сжимается отдельно в течение 180 мс. Регрессионный тест прошёл во всех профилях.
2. На 320 px форма занимала слишком много первого экрана. Кнопка перенесена к полю, параметры оставлены ниже, прогресс собран в одну строку со шкалой. Размеры управления сохранены; первый текст задачи появляется примерно на высоте 530 px.
3. Мобильный редактор имел лишнюю строку с неактивной ручкой. Она убрана; сохранение и отмена располагаются рядом, очистка срока — ниже.
4. Уточнены размеры подписей, переносы сроков и внутренние отступы, чтобы outline крайних кнопок не обрезался. Ненужная подсказка сортировки в пустом списке скрыта.
5. Открытие и закрытие редактора сопровождалось резким изменением высоты. Добавлен переход с измерением текущей высоты; reduced motion отключает его.
6. Старый тест клавиатуры не учитывал отдельные Tab-позиции нативного date input. Он проверяет достижимость следующего элемента, сохраняя проверку порядка и видимого фокуса.
7. dnd-kit создаёт визуальную копию переносимой строки. Тест ошибочно ожидал ровно один элемент с классом перетаскивания; исправлено ожидание, итоговый порядок и свойства по-прежнему проверяются полностью.
8. Быстрый reload иногда отменял незавершённую загрузку локального шрифта в WebKit. Добавлены preload и явное ожидание `document.fonts.ready` перед тестовыми переходами; ошибки загрузки ресурсов не игнорируются.
9. Один axe-снимок поймал промежуточные цвета смены темы. Проверка теперь ждёт окончания конечных анимаций и проверяет итоговую палитру обеих тем. Контрастные правила axe сохранены.
10. Версия корня lockfile синхронизирована с 2.0.0. Удалён неиспользуемый вспомогательный код теста.

## Визуальный аудит

До изменений приложение открыто в браузере; сохранён скриншот V1 с шириной рабочей области 688 px. После реализации проведены два прохода визуального ревью: сначала общая композиция и обе темы, затем узкие экраны, пустое состояние, редактирование и смешанный список с приоритетами, выполненным и просроченным.

В V2 область расширена до 1040 px и разделена по функциям. Типографика — Manrope с кириллицей, две локальные WOFF2-подгруппы одной гарнитуры. Поверхности, границы и состояния разработаны для обеих тем; на телефоне изменяется расположение элементов.

Градиенты, свечение, стеклянные панели, pill-кнопки, эмодзи, декоративные фигуры, случайные иконки и фиктивные метрики исключены при проектировании. Во время аудита убраны лишняя строка редактора и подсказка без списка; пересмотрена плотность мобильной формы. Прогресс показывает реальные данные, все оставшиеся иконки управляют действием или обозначают срок/приоритет.

Скриншоты для README — `docs/preview.png` и `docs/preview-dark.png`. Полные изображения обеих тем, мобильных профилей, редактора, пустого списка и длинного текста — локально в `artifacts/screenshots/`. HTML-отчёт — `playwright-report/index.html`, JSON — `artifacts/test-results.json`. Локальные отчёты и тестовые данные исключены из Git.

После последних изменений выполнен полный итоговый прогон пяти профилей. Последующая сборка с файлами лицензий имеет те же хеши JS/CSS, что и проверенная сборка.

## Референсы и лицензии

Актуальное содержимое всех четырёх репозиториев повторно изучено перед использованием в V2.

- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): рекомендации по композиции, фокусу, контрасту, типографике и reduced motion.
- [21st](https://github.com/serafimcloud/21st): изучены реализации полей и кнопок; состояния реализованы собственным CSS.
- [MG Styles 15](https://github.com/Vincentwei1021/mg-styles-15): изучены motion notes Flat Vector; применены короткое замедление и последовательность обратной связи.
- [GSAP](https://github.com/greensock/GSAP): рассмотрены easing и адаптивные настройки; для этого приложения достаточно CSS, Web Animations API и анимаций сортировки dnd-kit.
- [dnd-kit](https://dndkit.com/react/quickstart/): использован актуальный React API, не legacy-пакеты.

Компоненты референсов не копировались. Уведомления о лицензиях runtime-библиотек включены в `public/THIRD_PARTY_NOTICES.txt`, Manrope OFL — в `public/fonts/OFL.txt`; оба файла попадают в сборку.

## Ограничения и публикация

Физические Android/iPhone, реальная экранная клавиатура и экранный диктор не проверялись. Работа с клавиатурой проверена автоматически, уменьшение viewport имитирует доступную область при экранной клавиатуре. Touch drag и scroll проверены через Chromium CDP; в мобильном WebKit проверены касания основных действий, но не полный жест перетаскивания. WebKit в Playwright не заменяет Safari на реальном iPhone. Отдельный Google Chrome и Chrome DevTools не использовались; Chromium проверялся через Microsoft Edge.

GitHub API повторно проверен: HTTP 401 для сохранённой авторизации. Конфигурация/токен Netlify в локальном окружении отсутствуют. Публичные ресурсы не создавались, опубликованного URL нет и публичная версия не объявляется проверенной. Production-сборка, Git-история и инструкции DEPLOYMENT.md подготовлены. Пароли и токены в переписке не запрашивались, в проект не добавлялись.
