## Разрешения

Проверены 1920×1080, 1440×900, 1366×768, 1024×768, 820×1180, 768×1024, 320×640, 360×800, 375×812, 390×844, 430×932.

Для каждого размера использовались десять задач, включая слово из 200 символов. Проверялись отсутствие горизонтальной прокрутки, положение и область нажатия удаления, шрифт поля не меньше 16 px. Дополнительно тестировались пустой список, одна задача и сто задач с прокруткой до последней.

## Найденное и исправленное

1. ESLint обнаружил синхронное обновление сообщения из эффекта. В данном месте оно отражает результат записи во внешнее хранилище; добавлено локальное исключение с объяснением, остальные правила React Hooks сохранены.
2. Тест фильтра ожидал checked-состояние уже исчезнувшего из активного списка элемента. Тест исправлен: выполняется клик и проверяется итоговый список и счётчик. Приложение корректно меняло статус.
3. Измерение высоты 44 px однажды вернуло 43.999969 из-за численной погрешности transform во время появления. Проверка округляет значение до CSS-пикселя; целевая область в CSS остаётся 44×44 px.
4. Первые скриншоты захватывали промежуточные цвета анимаций. Итоговые снимки делаются с завершёнными анимациями, а reduced motion проверяется отдельно.
5. В зависимостях ESLint обнаружена уязвимая версия minimatch. Через `overrides` установлен minimatch 11.0.1+, после чего lint и браузерные проверки прошли, npm audit вернул 0 уязвимостей.

После первоначальной реализации выполнен полный функциональный прогон. После просмотра реальных скриншотов — повторная полная проверка. Затем добавлены Firefox и WebKit и выполнен итоговый прогон всех пяти профилей.

## Визуальный аудит

Просмотрены фактические скриншоты desktop, 320 px и 390 px, пустое состояние, обычный список и длинные названия. Проверены согласованность размеров, выравнивание, читаемость, переносы, кнопки и плотность списка.

Итог: тёплый фон, ширина 688 px, один приглушённый зелёный акцент, системный шрифт, небольшие скругления, разделители строк. Чекбокс и удаление имеют функциональное назначение. Градиенты, свечение, pill-кнопки, эмодзи, декоративные фигуры, вложенные карточки, рекламные заголовки и фиктивные метрики исключены при проектировании; удалять такие элементы после аудита не потребовалось.

Скриншот обычного интерфейса сохранён в `docs/preview.png`. Полные снимки разных профилей находятся локально в `artifacts/screenshots/`; HTML-отчёт — в `playwright-report/index.html`, машиночитаемый — в `artifacts/test-results.json`. Эти локальные отчёты и тестовые данные исключены из Git.

## Референсы

Код приложения написан самостоятельно; код и ассеты референсов не копировались, внешние библиотеки компонентов и анимации не подключались.

- [UI UX Pro Max](https://github.com/nextlevelbuilder/ui-ux-pro-max-skill): изучены рекомендации по фокусу, контрасту, переносам, адаптивности и reduced motion. Применены к небольшой рабочей области.
- [21st](https://github.com/serafimcloud/21st): изучен исходный код input, button и checkbox в `apps/web/components/ui`. Взяты принципы согласованных состояний и доступного фокуса, реализованные обычным CSS и нативными контролами.
- [MG Styles 15](https://github.com/Vincentwei1021/mg-styles-15): изучены описание процесса и Flat Vector motion notes. Для списка выбран короткий приход с замедлением, без постоянного движения.
- [GSAP](https://github.com/greensock/GSAP): рассмотрены управление последовательностями и easing. Для появления на 180 мс и transitions на 160 мс достаточно возможностей CSS.
