# Как устроен проект

## 1. Общая структура

`index.html` содержит контейнер приложения. `src/main.jsx` запускает React, а `src/App.jsx` описывает интерфейс и действия пользователя. `src/index.css` задаёт общие правила и цвета, `src/App.css` — расположение и состояния элементов. Для небольшого списка достаточно одного компонента, поэтому дополнительных слоёв архитектуры нет.

Каждая задача — обычный объект:

```js
{ id: 'уникальный-идентификатор', text: 'Подготовить резюме', completed: false }
```

`id` создаётся с помощью `crypto.randomUUID()`. Он помогает найти конкретную задачу и служит стабильным ключом React.

## 2. Зачем React

React связывает данные и интерфейс. Когда массив задач меняется, React обновляет список и счётчик. Нам не нужно вручную создавать или удалять HTML-элементы.

## 3. Что делает useState

`useState` хранит данные между отображениями компонента. В проекте это список задач, содержимое поля ввода, выбранный фильтр и сообщения. Вызов `setTasks` сообщает React, что данные изменились.

Массив не изменяется напрямую: для нового состояния используются новые массивы с помощью spread, `map` и `filter`. Функциональная запись `setTasks(current => ...)` работает с актуальным состоянием.

## 4. Зачем useEffect

`useEffect` синхронизирует React с внешней системой — localStorage. После изменения списка эффект записывает его в браузер. Зависимость `tasks` означает, что ввод текста или переключение фильтра не вызывает лишнюю запись.

Первое состояние считывается отдельной функцией `readSavedTasks`. При первом открытии эффект ничего не записывает: это не даёт автоматически затереть повреждённые данные. Сообщение об ошибке записи обновляется из эффекта; для этого обоснованно отключено одно правило React Hooks на конкретной строке.

## 5. Как добавляется задача

Форма вызывает `addTask` и по кнопке, и по Enter. `preventDefault()` предотвращает перезагрузку страницы. `trim()` убирает пробелы по краям. Пустая строка отклоняется, длина ограничена 200 символами. Создаётся новый объект, добавляется в массив; поле очищается, фокус возвращается в него.

Если открыт фильтр выполненных задач, после добавления включается «Все», чтобы новая задача была видна.

## 6. Как меняется статус

Чекбокс вызывает `toggleTask`. Метод `map` создаёт новый массив, меняя `completed` только у задачи с нужным `id`. CSS добавляет зачёркивание и более спокойный цвет. Повторное нажатие возвращает задачу в активное состояние.

Счётчик вычисляется из массива, поэтому отдельное состояние для него не нужно. Фильтрация влияет только на отображение, а не удаляет задачи из данных.

## 7. Как работает удаление

`deleteTask` использует `filter`: в новом массиве остаются все задачи, кроме выбранной. Остальные объекты сохраняют текст и статус. После удаления фокус переходит на соседнюю задачу или в поле ввода — управление клавиатурой не теряется.

## 8. Что такое localStorage

Это встроенное хранилище браузера для строк. `JSON.stringify` превращает массив в строку, а `JSON.parse` восстанавливает его. Ключ нашего списка — `todo-list.tasks.v1`.

Данные относятся к конкретному адресу сайта и профилю браузера. Они не отправляются на сервер и не синхронизируются между устройствами. Очистка данных сайта удалит список; приватный режим может не сохранять его после закрытия браузера.

## 9. Почему задачи переживают обновление

Изменённый массив записывается в localStorage. При следующем запуске `readSavedTasks` читает его и проверяет формат: массив, уникальные строковые `id`, непустые названия, допустимую длину и логический статус.

При повреждении приложение показывает пустой список с пояснением. Старое значение не перезаписывается до первого изменения списка. Если браузер запрещает доступ или место закончилось, `try/catch` предотвращает падение: текущий список продолжает работать, но без гарантии сохранения.

## 10. Как устроена адаптивность

Рабочая область имеет максимальную ширину 688 px и сужается вместе с окном. Flexbox распределяет место между полем и кнопкой. В CSS media query меняет отступы и заголовок на узком экране. `min-width: 0` и `overflow-wrap: anywhere` позволяют переносить даже длинные слова.

Удаление имеет область нажатия 44×44 px и постоянно видно. Нажатие на текст задачи также переключает чекбокс. Поле использует шрифт 16 px, есть заметный фокус. При `prefers-reduced-motion` анимации отключаются.

## 12. Как запустить и показать проект

Из папки проекта выполните `npm install`, затем `npm run dev`. Откройте адрес, который напечатает Vite. Для проверки готовой сборки выполните `npm run build` и `npm run preview`.

`npm run lint` проверяет код, `npm test` запускает браузерные сценарии. Подробности публикации на GitHub и Netlify находятся в DEPLOYMENT.md.
